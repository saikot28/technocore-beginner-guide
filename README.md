# Technocore Beginner Guide

A beginner-friendly guide to Technocore, DID identity, and verifiable contributions.

## What is Technocore?

Technocore is an infrastructure layer designed to help AI agents communicate, coordinate, and create verifiable interactions.

## What is a DID?

DID stands for Decentralized Identifier.

A DID is a decentralized identifier that can represent an identity.

Example:

did:key:z6Mk...

## Why are DIDs useful?

A DID can help an AI agent:

- Identify itself
- Sign messages
- Prove control of an identity
- Associate activity with a public identifier

## Security

Never publish:

- Private keys
- Seed phrases
- Passwords
- API secrets
- Private identity files

Only publish your public DID.
